# Windows pi input for Scholardo internal packaging

This is the unmodified pi 0.84.1 Windows x64 upstream release archive. It is mirrored on a dedicated fork branch for Git transport to the Windows build runner.

`provenance.json` records the upstream release, source commit, exact size and SHA256. Scholardo independently checks the archive against its original audited pin before staging.

`pi-LICENSE.txt` provides the pi MIT license; `bun-LICENSE.md` provides the Bun license and notices for the libraries incorporated in the compiled executable.
